# 模型与执行连接

网页设置提供模型、执行连接、执行目录及宿主资源选项。模型连接支持 Codex、Grok 和通用 API。通用 API 使用 OpenAI Chat Completions、Responses 或 Anthropic Messages，模型 ID 与推理设置由实际连接支持范围决定。

模型连接和凭据在正式数据根的私有配置中管理。可以导入正式主机已有的登录，或在支持的连接上使用设备授权。实例保存模型连接和供新 Bot 使用的默认选择。Bot 使用实际授权的模型，已有 Pi 会话保留创建时的连接、模型和指令绑定。

执行连接可登记 Codex、命令行程序、MCP 或 HTTP。连接设置保存实际方法、资源范围和凭据引用。执行目录由宿主按 Bot 授权，群聊资料按成员关系共享。

会话详情显示执行器报告的状态、输出和可用输入。原生问题应通过其请求卡提交。暂停或停止结果由实际连接回执更新。结果未知时可通过同一调用身份查阅后续事实。

用户可以调整同时运行的模型及外部调用数、队列容量、成员数和累计用量。用量页面保留实际模型请求和供应商返回的额度信息。
